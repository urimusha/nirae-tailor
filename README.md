# NIRÆ Tailor

Dalamud plugin repository for NIRÆ Tailor (friends only).

Install: in game `/xlsettings` → Experimental → Custom Plugin Repositories → add

    https://raw.githubusercontent.com/urimusha/nirae-tailor/main/repo.json

tick it, Save, then `/xlplugins` → All Plugins → "NIRÆ Tailor" → Install, and `/tailor`.
The first open downloads the plugin's own Python (one time, about 70 MB). Needs Penumbra; the NIRÆ Body mod for ports
to NIRÆ; the FluxHD2 and [IVCS] FluxHD2 mods for ports to a Lalafell.
